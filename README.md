## 上传规范

- 图片直接传原文件，不要转 base64 / 不要改扩展名
- 文件名：`系列_名称.jpg`（如 `zoggy_moyu.jpg`），英文小写+下划线
- 新系列先建文件夹，再传图，最后在这张表里登记一行
